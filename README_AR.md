# وقتي — تطبيق تنظيم الوقت

تطبيق عربي RTL من نوع SPA/PWA، بلا مكتبات أو اتصالات خارجية. افتح `index.html` للاستخدام المحلي، أو ارفع ملفات المجلد كلها إلى جذر GitHub Pages حتى يعمل التثبيت والأوفلاين.

## البيانات المستوردة
تم استيراد 103 مهام من أوراق السبت إلى الجمعة في `weekly_daily_planner.xlsx` الموجود في مكتبة المحادثة، مع نقل الحالات والأولويات والملاحظات. خانات النوم «ن» تحولت لإعداد نوم، والمهام المركبة بعلامة + حُفظت معها عناصر فرعية. تم إنشاء قواعد تكرار مستقبلية مبدئية لروتين الورد/الأذكار وبعض مهام المحتوى والجرد والبيع والأقساط، بناءً على تكرارها في الشيت.

## تشغيل ونشر
- محليًا: افتح `index.html` في متصفح حديث.
- للاستضافة والتثبيت: ارفع `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png` إلى نفس مجلد GitHub Pages.
- لا توجد خدمة مزامنة سحابية مفعلة حاليًا؛ البيانات تحفظ في المتصفح الحالي. صدّر JSON للنسخ الاحتياطي.
- تنبيهات النظام لا تُضمن بعد إغلاق الصفحة؛ استخدم تصدير `.ics` وتقويم الهاتف أو المنبه.
- ملف `time_system.md` لم يكن متاحًا وقت البناء، لذا لم يتم دمج أي محتوى منه.


## تقسيم المهام اليومي والأسبوعي والشهري
أضيفت شاشة «تقسيم المهام» من شريط التنقل، وفيها تبويبات يومي/أسبوعي/شهري مع إحصائيات محسوبة تلقائيًا وتنقل بين الفترات. بعد رفع الملفات الجديدة حدّث الصفحة؛ تم تغيير إصدار ذاكرة التخزين المؤقت لإجبار المتصفح على تحميل النسخة الجديدة.

# يومك | Yomak — نسخة PWA أولية

## الموجود في النسخة
- واجهة عربية RTL متجاوبة.
- إضافة مهام بتاريخ ووقت وأولوية، إتمامها، تغيير موعدها أو حذفها.
- عادات مع متابعة إنجاز اليوم.
- مؤقت تركيز 25/15/5 دقائق.
- حفظ محلي عبر IndexedDB.
- تصدير/استيراد نسخة احتياطية JSON.
- Service Worker وملف manifest للتثبيت والعمل دون اتصال بعد تحميل التطبيق أول مرة.

## النشر عبر GitHub Pages
1. أنشئ مستودعًا عامًا باسم `yomak` على GitHub.
2. ارفع كل ملفات هذا المجلد إلى جذر المستودع (وليس داخل مجلد إضافي).
3. من Settings > Pages، اختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
4. انتظر رابط النشر الظاهر في صفحة Pages.
5. افتح الرابط أول مرة مع الإنترنت، وانتظر اكتمال التحميل، ثم اختبره بعد فصل الإنترنت.
6. على Android في Chrome: القائمة ⋮ > Add to Home screen أو Install app إذا ظهرت.

## ملاحظات مهمة
- المزامنة السحابية غير موجودة في هذه النسخة؛ الحالة المعروضة في الواجهة توضح ذلك.
- GitHub Pages يستضيف ملفات الواجهة فقط ولا يوفر قاعدة بيانات أو حسابات مستخدمين.
- البيانات المحلية مرتبطة بمتصفح/جهاز المستخدم. استخدم التصدير الاحتياطي بانتظام حتى اختبار المزامنة لاحقًا.
- لا تضع مفاتيح سرية في ملفات JavaScript العامة. عند إضافة Supabase لاحقًا، استخدم مفتاح publishable/anon فقط مع سياسات RLS صحيحة، ولا تضع service_role key في الواجهة.
- هذا نموذج أولي للاختبار، وليس بعدُ نظام مزامنة متعدد الأجهزة.
